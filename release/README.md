# 📦 Calibrey Standalone APK Release

This directory contains the ready-to-install Android Application Package (APK) for **Calibrey**.

## 📥 Direct Download

- **File**: [`Calibrey-v1.0.apk`](./Calibrey-v1.0.apk?raw=true)
- **Target OS**: Android 7.0 (API Level 24) to Android 15+ (API Level 36)
- **Architecture**: Universal (ARM64, ARM32, x86_64)

### How to Download from GitHub:
1. Click on **[`Calibrey-v1.0.apk`](./Calibrey-v1.0.apk?raw=true)**.
2. Click the **Download** (or **View Raw**) button in the GitHub file viewer.
3. The APK will download directly onto your device.

---

## 📲 How to Install on Your Android Device

1. Once downloaded, open your phone's **Files** or **Downloads** app.
2. Tap `Calibrey-v1.0.apk`.
3. If prompted with *"Install Unknown Apps"*, tap **Settings** and toggle **"Allow from this source"** to ON.
4. If Google Play Protect shows a notification for this development build, tap **"More details"** $\rightarrow$ **"Install anyway"**.
5. Tap **Install** and then **Open**!
