## 📲 Step-by-Step Installation on Android

### Step 1: Open Downloads
Open your device's **Files** or **Downloads** app and tap `Calibrey-v1.0.apk`.

### Step 2: Grant Permission (If Prompted)
If you see *"For your security, your phone is not allowed to install unknown apps from this source"*:
1. Tap **Settings**.
2. Turn **ON** the toggle for **"Allow from this source"**.
3. Press the back button.

### Step 3: Google Play Protect
Because this is a development build compiled directly from source code:
1. Tap **"More details"** (or small arrow).
2. Tap **"Install anyway"**.

### Step 4: Launch the App
Tap **Install** $\rightarrow$ wait 3 seconds $\rightarrow$ tap **Open**!

## 🔧 Troubleshooting "App Not Installed" or "Parse Error"

| Issue / Error | Exact Cause | How to Fix |
| :--- | :--- | :--- |
| **"App not installed"** | Old version of app already installed with conflicting debug signature | **Uninstall** any previous version of "Calibrey" or "My Application" from your phone first, then tap `Calibrey-v1.0.apk` again. |
| **"There was a problem parsing the package"** | Incomplete download or saved as `.html` / `.zip` | Check file size: must be ~23MB. Ensure filename ends in `.apk`. Re-download using the raw download link. |
| **"Blocked by Play Protect"** | Android security warning for sideloaded development APKs | Tap **"More details"** then tap **"Install anyway"**. |
| **"Install Unknown Apps" blocked by employer/family link** | Device administration restriction | Enable developer sideloading in device Settings under *Security* $\rightarrow$ *Install unknown apps*. |
